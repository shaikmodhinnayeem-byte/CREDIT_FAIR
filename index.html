2. Models and Working Principle
Logistic Regression
  • Linear model for classification
  • Uses logistic (sigmoid) function
  • Outputs probability (0 to 1)
  • Simple and interpretable
  • Works well with linearly separable data
P(y = 1) = 11 + e-(β₀ + β₁x₁ + ... + βₙxₙ)
Decision Tree
  • Tree-based model
  • Splits data based on feature conditions (e.g., loan_amnt < 10000)
  • Easy to understand and visualize
  • Can capture non-linear relationships
  • May overfit if not pruned
Random Forest
  • Ensemble of multiple decision trees
  • Uses bagging (bootstrap sampling)
  • Reduces overfitting
  • More robust and better performance than single decision tree
  • Can handle non-linear relationships and feature interactions

✖ Requires feature scaling

Best overall performance, real-world deployment, complex data
